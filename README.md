O site da **RM iPhones** foi desenvolvido unindo as melhores práticas das três maiores referências do mercado nacional:
- **Design System Dark Ultra-Premium:** Estética Titanium & Deep Obsidian com acabamento refinado e tipografia cirúrgica (padrão Tec2D).

## 🚀 Como Executar Localmente

```bash
# Instalar dependências (caso necessário)
npm install

# Iniciar servidor local
npm run dev
# ou
npm start
```

O servidor estará disponível em: `http://localhost:3000`

## 🛠️ Tecnologias Utilizadas

- **Frontend Core:** HTML5 Semântico, CSS3 Moderno com Tokens de Design (Tailwind CSS Architecture) e JavaScript Modular (ES6+).
- **Performance:** Formato WebP otimizado de última geração com carregamento assíncrono (LCP < 1.0s).
- **Infraestrutura:** Node.js HTTP Server com suporte a Range requests (streaming de vídeo) e Cloudflare Pages Functions.
